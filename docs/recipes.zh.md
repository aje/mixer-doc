# :material-book-open-variant: 配方和分配指南

本指南说明了如何使用 Mixer 应用中的配方和分配功能。

## 概览

配方功能允许您浏览可用配方，选择特定版本或大小，并启动自动分配过程。

## 配方列表

主屏幕显示所有可用配方。

![配方列表占位符](assets/images/placeholder.png)
*所有可用配方的列表。*

- **类别**：使用顶部的选项卡按类别筛选配方。
- **配方卡片**：每个配方显示其名称、唯一代码和类型。
- **检查可用性**：使用“检查可用性”按钮查看哪些配方可以使用机器当前加载的原料制作。

## 配方详情

选择配方会显示更多信息和准备选项。

![配方详情占位符](assets/images/placeholder.png)
*配方详情和版本选择界面。*

### 1. 版本选择
许多配方有不同的变体或大小。您可以选择所需的版本，所需的原料和总重量将自动更新。

### 2. 原料状态
如果出现以下情况，应用将发出警告：
- 缺少任何原料。
- 某种原料剩余不足。
- 机器的分配器需要校准。

### 3. 原料列表
您可以查看所需的所有原料以及所选版本所需的确切数量。

### 4. 启动过程
- **开始分配**：这将开始自动混合和分配过程。
- **模式选择**：根据机器设置，您可以在“快速”或“标准”分配模式之间进行选择。

## 分配过程

在机器工作时，您可以在屏幕上看到实时进度。机器处理每种原料的精确测量。如果发生任何问题，例如泵故障或原料耗尽，应用将立即通知您。

![分配进度占位符](assets/images/placeholder.png)
*机器正在分配时的实时进度。*

## 结果和完成

过程完成后，将显示摘要：
- **状态**：确认过程是否成功。
- **重量精度**：显示实际分配量与目标重量的对比。
- **自动记录**：机器会自动记录生产数据以供您参考。

![分配结果占位符](assets/images/placeholder.png)
*显示结果和重量精度的完成摘要。*
