# :material-clipboard-check: Machine Testing Checklist

Complete this checklist before sending the machine to the store.

## Pots

- [ ] Bind an ingredient to a pot and confirm that the ingredient is shown.
  ![Bind Pot Placeholder](assets/images/placeholder.png)
- [ ] Open the pot menu, select **Unbind Pot**, and confirm that the ingredient is removed.
  ![Unbind Pot Placeholder](assets/images/placeholder.png)
- [ ] Calibrate each pot and confirm that the calibration is complete.
  ![Calibrate Pots Placeholder](assets/images/placeholder.png)

## Machine Components

- [ ] Test the screen and confirm that it responds to touch.
  ![Screen Test Placeholder](assets/images/placeholder.png)
- [ ] Test the network connection.
  ![Network Test Placeholder](assets/images/placeholder.png)
- [ ] Test the scale and confirm that it reads weight correctly.
  ![Scale Test Placeholder](assets/images/placeholder.png)
- [ ] Test the scanner.
  ![Scanner Test Placeholder](assets/images/placeholder.png)
- [ ] Test the sound.
  ![Sound Test Placeholder](assets/images/placeholder.png)
- [ ] Test the heater, if installed.
  ![Heater Test Placeholder](assets/images/placeholder.png)
- [ ] Run the motors and confirm stable operation.
  ![Motor Stability Test Placeholder](assets/images/placeholder.png)

## Recipes and Accuracy

- [ ] Dispense multiple recipes and confirm that each recipe completes successfully.
  ![Multiple Recipes Test Placeholder](assets/images/placeholder.png)
- [ ] Check the dispensed amount for each recipe against its required specification and confirm the accuracy.
  ![Recipe Accuracy Test Placeholder](assets/images/placeholder.png)

## Refill

- [ ] Refill a pot and confirm that the refill process completes successfully.
  ![Refill Test Placeholder](assets/images/placeholder.png)
- [ ] Confirm that the machine is ready before sending it to the store.
  ![Ready Machine Placeholder](assets/images/placeholder.png)
