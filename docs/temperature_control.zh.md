# :material-thermometer: 温度控制

如果容器配有加热器，您可以控制其温度。

1. 点击容器卡片上的**温度图标**，或通过**容器菜单**访问。
   ![Open Temperature Control Placeholder](assets/images/cn/pots/pot-temp-btn.png)
2. 使用滑块设置所需温度，通常为 10°C 至 40°C。
   ![Set Temperature Placeholder](assets/images/cn/pots/temp-dialog.png)
3. 点击**设置**开始加热。

       ![Start Heating Placeholder](assets/images/cn/pots/temp-loading.png)

4. 实时查看**当前温度**。 
5. 随时点击**停止**关闭加热器。
