# :material-thermometer: 温度控制

如果容器配有加热器，您可以控制其温度。

1. 点击容器卡片上的**温度图标**，或通过**容器菜单**访问。
   ![打开温度控制占位符](assets/images/placeholder.png)
2. 使用滑块设置所需温度，通常为 10°C 至 40°C。
   ![设置温度占位符](assets/images/placeholder.png)
3. 点击**设置**开始加热。
   ![开始加热占位符](assets/images/placeholder.png)
4. 实时查看**当前温度**。
   ![当前温度占位符](assets/images/placeholder.png)
5. 随时点击**停止**关闭加热器。
   ![停止加热占位符](assets/images/placeholder.png)
