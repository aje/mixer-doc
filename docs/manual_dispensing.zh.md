# :material-scale-balance: 手动分配

您可以手动分配指定数量的原料。

1. 打开**容器**页面。
   ![打开容器占位符](assets/images/placeholder.png)
2. 点击要分配的容器。容器详情会在侧边栏中打开。
   ![打开容器详情占位符](assets/images/placeholder.png)
3. 选择或输入所需的重量，单位为克（g）。
   ![设置分配数量占位符](assets/images/placeholder.png)
4. 将杯子放在分配器下方。
   ![放置杯子占位符](assets/images/placeholder.png)
5. 点击**分配**。
   ![开始手动分配占位符](assets/images/placeholder.png)
6. 查看实时分配重量和最终准确度摘要。
   ![分配摘要占位符](assets/images/placeholder.png)
7. 如需中断流程，点击**停止**。
   ![停止分配占位符](assets/images/placeholder.png)
