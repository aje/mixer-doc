# :material-link-variant: Binding and Unbinding Ingredients

1. Open the **Pots** screen.
   ![Open Pots Placeholder](assets/images/placeholder.png)
2. Tap a pot with no ingredient assigned.
   ![Select Empty Pot Placeholder](assets/images/placeholder.png)
3. Select an ingredient from the available materials list.
   ![Select Ingredient Placeholder](assets/images/placeholder.png)
4. Confirm that the ingredient name appears on the pot.
   ![Bound Ingredient Placeholder](assets/images/placeholder.png)

## Unbinding an Ingredient

1. Open the **Pots** screen.
   ![Open Pots Placeholder](assets/images/placeholder.png)
2. Tap the **Menu icon (three vertical dots)** next to the pot.
   ![Open Pot Menu Placeholder](assets/images/placeholder.png)
3. Select **Unbind Pot**.
   ![Unbind Pot Placeholder](assets/images/placeholder.png)
4. Confirm the action.
   ![Confirm Unbinding Placeholder](assets/images/placeholder.png)
