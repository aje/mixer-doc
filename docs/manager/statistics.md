# :material-chart-bar: Statistics

Statistics turn a machine's production records into charts and totals so you can see how much has been produced over a period of time.

## Overview

Statistics are available per machine, from the **Production Records** section of the machine's details page. Open a machine (see **[Machines](machines.md#machine-details)**) and open its **statistics** view.

## Choosing a Time Range

Statistics default to **today**. Use the range controls to change the period:

- **Today**
- **Yesterday**
- **Last 7 days**
- **Custom** – pick a start and end date and apply.

## Reading the Charts

The statistics view summarizes production for the selected range, including production counts and error totals. Use the **exclude cancelled** toggle to leave cancelled or stopped productions out of the error totals.

For the underlying, row‑by‑row data, see **[Production Records](production_records.md)**.
