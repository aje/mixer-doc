# :material-clipboard-list: Recipes

The **Recipes** screen is where you create and manage the recipes that machines can produce. From here you can also import and export recipes as Excel files and distribute them to stores.

## Overview

The recipe list shows each recipe's image, code, name, external code, category, creation date, status and remark.

![Recipes list](../assets/images/placeholder.png)

*Screenshot placeholder: the recipes list.*

- **Search** – type a keyword in the search box to filter recipes.
- **Category** – use the category selector to filter by category.

## Managing Recipes

### Create a recipe

1. Click **New**.
2. Fill in the basic information.
3. Save.

After creating a recipe you can configure its **[ingredients](recipe_ingredients.md)**, **[customizations](recipe_customization.md)** and **[combinations](recipe_combinations.md)**.

### Edit a recipe

1. Click the **edit** icon on the recipe row.
2. Update the basic information.
3. Save.

### Copy a recipe

Click the **copy** icon on the recipe row to create a new recipe pre‑filled from the selected one.

### Enable or disable a recipe

Use the **status** toggle in the recipe row.

### Delete a recipe

- **Single** – click the **delete** icon on the recipe row and confirm.
- **Batch** – select recipes with the checkboxes, then click **Delete** in the toolbar and confirm.

## Categories and Recipe Groups

- Use the **category** selector to filter the list by category.
- Delete a category with the **delete** icon next to it in the selector.
- Choose **New** at the bottom of the selector to create a recipe group.

## Importing Recipes from Excel

1. Click **Upload Excel**.
2. Select the Excel file. A **preview** of the recipes to be imported is shown.
3. Confirm the import.

![Import recipes preview](../assets/images/placeholder.png)

*Screenshot placeholder: the Excel import preview dialog.*

## Exporting Recipes to Excel

1. Select one or more recipes with the checkboxes.
2. Click **Download** in the toolbar. The selected recipes are exported as an Excel file.

## Distributing Recipes to Stores { #distributing-recipes-to-stores }

1. Select one or more recipes with the checkboxes.
2. Click **Distribute** in the toolbar.
3. In the dialog, choose whether to distribute to a single **Store** or to a **Store Group**.
4. Select the target store or group and confirm.

![Distribute recipes](../assets/images/placeholder.png)

*Screenshot placeholder: the distribute dialog with the Store and Store Group tabs.*

You can also manage a store's recipes from the **[Stores](stores.md#store-recipes)** screen.

## Recipe Configuration { #recipe-configuration }

Click a recipe row to open its details page, where you configure:

- **[Basic Info](recipes.md)** – the recipe's main information.
- **[Customizations](recipe_customization.md)** – the options attached to the recipe.
- **[Ingredients](recipe_ingredients.md)** – the materials used by the recipe.
- **[Combinations](recipe_combinations.md)** – the ingredient amounts for each customization combination.
- **History** – the change history of the recipe.
