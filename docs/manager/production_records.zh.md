# :material-truck-delivery: 生产记录

**生产记录**界面列出各机器生产的饮品，便于你查看生产内容并排查问题。

## 概览

每条记录显示所生产的配方、订单信息以及结果。点击配方名称可快速按该配方筛选列表。

![生产记录](../assets/images/placeholder.png)

*截图占位：生产记录列表。*

## 筛选记录

使用列表顶部的筛选器缩小记录范围：

- **关键字** —— 按配方搜索记录。
- **订单** —— 按记录是否有订单筛选。
- **状态** —— 按记录状态筛选。
- **错误** —— 筛选以错误结束的记录。
- **日期范围** —— 将记录限制在起止日期之间。

![生产记录筛选](../assets/images/placeholder.png)

*截图占位：订单、状态、错误和日期范围的筛选弹出框。*

## 物料记录

打开某条记录的**物料记录**，查看该次生产所出料的原料及用量。

![物料记录](../assets/images/placeholder.png)

*截图占位：某条生产记录的物料记录对话框。*

## 单台机器的记录

单台机器的生产记录也可在机器详情页中查看。参见 **[机器](machines.md#machine-details)**。若需查看使用图表和总量，请参见 **[统计](statistics.md)**。
