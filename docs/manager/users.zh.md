# :material-account-group: 用户

**用户**界面用于管理可登录经理后台的账户。

## 概览

用户列表显示每个账户的用户名、全名、电话号码、状态和创建日期。

![用户列表](../assets/images/placeholder.png)

*截图占位：用户列表。*

## 管理用户

### 创建用户

1. 点击**新建**。
2. 输入用户名、全名、电话号码和密码。
3. 保存。

### 编辑用户

1. 点击用户行上的**编辑**图标。
2. 更新字段。
3. 保存。

### 更改用户密码

1. 点击用户行上的**密码**图标。
2. 输入并确认新密码。
3. 保存。

### 启用或停用用户

使用用户行中的**状态**开关。

### 删除用户

1. 点击用户行上的**删除**图标。
2. 在对话框中确认。
