# :material-format-list-bulleted-type: Customizations

Customizations are reusable options that can be attached to recipes, such as *Size*, *Sugar level* or *Temperature*. Each customization has a code, a name and a list of values. This page explains how to manage them.

> To attach a customization to a specific recipe, see **[Recipe Customization](recipe_customization.md)**.

## Overview

The **Customizations** screen lists each customization's code, name, values and status.

## Managing Customizations

### Create a customization

1. Click **New**.
2. Enter the code, name and the list of values.
3. Save.

### Edit a customization

1. Click the **edit** icon on the row.
2. Update the fields and values.
3. Save.

### Enable or disable a customization

Use the **status** toggle in the row.

### Delete a customization

1. Click the **delete** icon on the row.
2. Confirm in the dialog.
