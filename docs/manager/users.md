# :material-account-group: Users

The **Users** screen lets you manage the accounts that can sign in to the manager dashboard.

## Overview

The user list shows each account's username, full name, phone number, status and creation date.

## Managing Users

### Create a user

1. Click **New**.
2. Enter the username, full name, phone number and password.
3. Save.

### Edit a user

1. Click the **edit** icon on the user row.
2. Update the fields.
3. Save.

### Change a user's password

1. Click the **password** icon on the user row.
2. Enter and confirm the new password.
3. Save.

### Enable or disable a user

Use the **status** toggle in the user row.

### Delete a user

1. Click the **delete** icon on the user row.
2. Confirm in the dialog.
