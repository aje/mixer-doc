# :material-view-grid-plus: 配方组合

组合定义了配方在其各个定制值组合下所使用的确切原料用量。本页是 **[配方配置](recipes.md#recipe-configuration)** 的一部分。

## 概览

当配方带有定制项时（例如*规格：小/大* 和 *糖度：50%/100%*），系统会为所选值的每一种可能组合生成一行。对于每种组合，你需要输入配方使用每种原料的用量。

![配方组合](../assets/images/placeholder.png)

*截图占位：组合表，每种原料一列，每种定制组合一行。*

## 前提条件

在配置组合之前，请确保配方已经：

- 选择了 **[原料](recipe_ingredients.md)**，并且
- 选择了 **[定制项](recipe_customization.md)**。

## 设置原料用量

1. 打开配方详情并进入**组合**部分。
2. 对于每一行组合，在每个原料列中输入用量。
3. 需要时，使用每种组合的**其他**选项为该组合设置附加值。
4. 保存更改。

**总计**会根据你输入的用量自动计算，便于你一目了然地核对每种组合。
