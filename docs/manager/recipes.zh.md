# :material-clipboard-list: 配方

**配方**界面用于创建和管理机器可生产的配方。你还可以在此将配方以 Excel 文件导入和导出，并将其分发到商店。

## 概览

配方列表显示每个配方的图片、编码、名称、外部编码、类别、创建日期、状态和备注。

![配方列表](../assets/images/placeholder.png)

*截图占位：配方列表。*

- **搜索** —— 在搜索框中输入关键字以筛选配方。
- **类别** —— 使用类别选择器按类别筛选。

## 管理配方

### 创建配方

1. 点击**新建**。
2. 填写基本信息。
3. 保存。

创建配方后，你可以配置其 **[原料](recipe_ingredients.md)**、**[定制项](recipe_customization.md)** 和 **[组合](recipe_combinations.md)**。

### 编辑配方

1. 点击配方行上的**编辑**图标。
2. 更新基本信息。
3. 保存。

### 复制配方

点击配方行上的**复制**图标，根据所选配方预填充创建一个新配方。

### 启用或停用配方

使用配方行中的**状态**开关。

### 删除配方

- **单个** —— 点击配方行上的**删除**图标并确认。
- **批量** —— 用复选框选择配方，然后点击工具栏中的**删除**并确认。

## 类别与配方分组

- 使用**类别**选择器按类别筛选列表。
- 在选择器中点击类别旁的**删除**图标可删除该类别。
- 在选择器底部选择**新建**可创建配方分组。

## 从 Excel 导入配方

1. 点击**上传 Excel**。
2. 选择 Excel 文件。系统会显示将要导入配方的**预览**。
3. 确认导入。

![导入配方预览](../assets/images/placeholder.png)

*截图占位：Excel 导入预览对话框。*

## 导出配方到 Excel

1. 用复选框选择一个或多个配方。
2. 点击工具栏中的**下载**。所选配方将导出为 Excel 文件。

## 将配方分发到商店 { #distributing-recipes-to-stores }

1. 用复选框选择一个或多个配方。
2. 点击工具栏中的**分发**。
3. 在对话框中，选择分发到单个**商店**还是**商店分组**。
4. 选择目标商店或分组并确认。

![分发配方](../assets/images/placeholder.png)

*截图占位：包含商店与商店分组标签页的分发对话框。*

你也可以在 **[商店](stores.md#store-recipes)** 界面管理某个商店的配方。

## 配方配置 { #recipe-configuration }

点击配方行可打开其详情页，在其中配置：

- **[基本信息](recipes.md)** —— 配方的主要信息。
- **[定制项](recipe_customization.md)** —— 附加到配方的选项。
- **[原料](recipe_ingredients.md)** —— 配方使用的原料。
- **[组合](recipe_combinations.md)** —— 每个定制组合的原料用量。
- **历史** —— 配方的变更历史。
