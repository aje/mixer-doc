# :material-bottle-tonic: 配方原料

每个配方都会使用一组原料（物料）。本页介绍如何选择配方使用哪些原料。它是 **[配方配置](recipes.md#recipe-configuration)** 的一部分。

> 原料本身在 **[原料](ingredients.md)** 界面创建和管理。在此处你只需选择配方使用哪些已有原料。

## 查看配方原料

打开某个配方的详情页。**物料**部分列出配方使用的原料及其编码、名称、有效期和分组。

![配方原料](../assets/images/placeholder.png)

*截图占位：配方原料（物料）部分。*

## 编辑配方原料

1. 点击物料部分中的**编辑**图标。
2. 使用原料选择器添加或移除原料。你可以按名称搜索原料。
3. 点击**保存**。

更改原料后，你可以在 **[配方组合](recipe_combinations.md)** 中按选项设置其用量。
