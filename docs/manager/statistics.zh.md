# :material-chart-bar: 统计

统计将机器的生产记录转化为图表和总量，让你了解一段时间内的产量。

## 概览

统计按机器提供，位于机器详情页的**生产记录**部分。打开某台机器（参见 **[机器](machines.md#machine-details)**）并打开其**统计**视图。

![统计](../assets/images/placeholder.png)

*截图占位：带图表的机器统计视图。*

## 选择时间范围

统计默认显示**今天**。使用范围控件更改时间段：

- **今天**
- **昨天**
- **最近 7 天**
- **自定义** —— 选择起止日期并应用。

## 查看图表

统计视图汇总所选范围内的生产情况，包括生产数量和错误总数。使用**排除已取消**开关可将已取消或已停止的生产从错误总数中剔除。

若需查看底层的逐条数据，请参见 **[生产记录](production_records.md)**。
