# :material-account-tie: 经理文档

Mixer 网页后台的**经理**区域用于管理产品（配方、原料和定制项）、组织商店与机器、监控生产以及管理用户账户。

## 概览

经理菜单分为两个部分：

**产品管理**

- **[配方](recipes.md)** —— 创建和管理配方，从 Excel 导入/导出，并分发到商店。
- **[原料](ingredients.md)** —— 管理配方中使用的原料。
- **[定制项](customizations.md)** —— 管理可附加到配方上的可复用选项（例如糖度或规格）。
- **[生产记录](production_records.md)** —— 查看各机器生产的饮品。

**设置**

- **[商店](stores.md)** —— 将商店分组并为其分配配方。
- **[机器](machines.md)** —— 将机器绑定到商店、设置机器密码并查看机器数据。
- **[用户](users.md)** —— 管理可登录后台的账户。

## 典型流程

经理常见的端到端流程如下：

1. 创建所需的 **[原料](ingredients.md)** 和 **[定制项](customizations.md)**。
2. 创建 **[配方](recipes.md)** 并配置其原料、定制项和组合。
3. 将配方 **[分发到商店](recipes.md#distributing-recipes-to-stores)**。
4. 组织 **[商店](stores.md)** 并将 **[机器绑定](machines.md)** 到商店。
5. 监控 **[生产记录](production_records.md)** 和 **[统计](statistics.md)**。
