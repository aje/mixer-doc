# :material-format-list-bulleted-type: 定制项

定制项是可附加到配方上的可复用选项，例如*规格*、*糖度*或*温度*。每个定制项都有编码、名称和一组值。本页介绍如何管理它们。

> 若要将定制项附加到具体配方，请参见 **[配方定制](recipe_customization.md)**。

## 概览

**定制项**界面列出每个定制项的编码、名称、值和状态。

## 管理定制项

### 创建定制项

1. 点击**新建**。
2. 输入编码、名称和值列表。
3. 保存。

### 编辑定制项

1. 点击行上的**编辑**图标。
2. 更新字段和值。
3. 保存。

### 启用或停用定制项

使用行中的**状态**开关。

### 删除定制项

1. 点击行上的**删除**图标。
2. 在对话框中确认。
