# :material-tune-variant: 配方定制

配方可以提供诸如规格或糖度等定制选项。本页介绍如何将定制项附加到配方。它是 **[配方配置](recipes.md#recipe-configuration)** 的一部分。

> 定制项在 **[定制项](customizations.md)** 界面创建和管理。在此处你只需选择哪些已有定制值适用于该配方。

## 查看配方定制

打开某个配方的详情页。**定制项**部分按名称分组列出所有定制项，并显示该配方选中了哪些值。

![配方定制](../assets/images/placeholder.png)

*截图占位：配方定制部分。*

## 编辑配方定制

1. 点击定制项部分中的**编辑**图标。
2. 勾选或取消勾选适用于该配方的定制值。使用**全选**可切换所有值。
3. 点击**保存**。

所选的定制值决定了你在 **[配方组合](recipe_combinations.md)** 中配置的组合。
