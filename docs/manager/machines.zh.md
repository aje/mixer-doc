# :material-coffee-maker: 机器

**机器**界面列出你可访问的机器，并可将其绑定到商店、设置密码，以及查看每台机器的配置和数据。

> 机器在工厂设置流程中注册。在经理后台中，你对机器进行配置和监控，但不在此处创建或删除机器。

## 概览

机器列表显示每台机器的 UUID、PLC UUID、型号、硬件版本、备注、所绑定的商店以及创建日期。

![机器列表](../assets/images/placeholder.png)

*截图占位：机器列表。*

## 将机器绑定到商店

- 如果机器**未绑定**，点击**绑定到商店**，选择商店并确认。
- 如果机器**已绑定**，其商店名称显示为按钮；点击可更改商店。

## 解绑机器

1. 点击已绑定商店旁的**解绑**图标。
2. 在对话框中确认。机器将从商店分离。

## 更改机器密码

1. 点击机器行中的**密码**图标。
2. 输入并确认新密码。
3. 保存。

## 通道

点击**通道**打开机器的通道配置，其中显示机器的料罐及绑定的原料。

![机器通道](../assets/images/placeholder.png)

*截图占位：机器通道对话框。*

## 机器详情 { #machine-details }

点击机器行可打开其详情页，包含：

- **基本信息** —— 机器的主要信息。
- **通道** —— 料罐及其绑定的原料。
- **生产记录** —— 该机器生产的饮品及统计。参见 **[生产记录](production_records.md)** 和 **[统计](statistics.md)**。
- **清洗** —— 机器的清洗数据。
- **活动** —— 机器的活动日志。
