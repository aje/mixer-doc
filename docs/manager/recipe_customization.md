# :material-tune-variant: Recipe Customization

A recipe can offer customization options such as size or sugar level. This page explains how to attach customizations to a recipe. It is part of the **[recipe configuration](recipes.md#recipe-configuration)**.

> Customizations are created and managed on the **[Customizations](customizations.md)** screen. Here you only choose which existing customization values apply to the recipe.

## Viewing the Recipe Customizations

Open a recipe's details page. The **Customizations** section lists all customizations grouped by name, showing which values are selected for this recipe.

## Editing the Recipe Customizations

1. Click the **edit** icon in the Customizations section.
2. Check or uncheck the customization values that should apply to the recipe. Use **Select all** to toggle every value.
3. Click **Save**.

The selected customization values determine the combinations you configure in **[Recipe Combinations](recipe_combinations.md)**.
