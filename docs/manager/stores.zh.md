# :material-store: 商店

商店代表运行机器的实体门店。本页介绍如何将商店分组、创建和编辑商店、关联机器，以及管理分配给每个商店的配方。

## 概览

**商店**界面分为两个区域：

- **商店分组**（左侧）—— 用于组织商店的分组树。
- **商店**（右侧）—— 商店列表，可按所选分组筛选。

![商店界面](../assets/images/placeholder.png)

## 商店分组

使用左侧的分组树来筛选和组织商店。

- 选择**全部**可列出所有商店，或选择某个分组仅列出该分组的商店。
- 使用**展开/收起**按钮显示或隐藏分组面板。
- 点击**设置**（齿轮）图标打开**商店分组**管理器，在其中创建、重命名和删除分组。

## 管理商店

### 创建商店

1. （可选）在左侧选择一个分组，使新商店创建在该分组下。
2. 点击**新建**。
3. 填写商店信息（编码、名称、类型、分组、外部编码、标签、用户）。
4. 保存。

### 编辑商店

1. 点击商店行上的**编辑**图标。
2. 更新字段。
3. 保存。

### 启用或停用商店

使用商店行中的**状态**开关来启用或停用商店。

### 删除商店

1. 点击商店行上的**删除**图标。
2. 在对话框中确认。

## 将机器关联到商店

1. 点击商店行上的**机器**图标，打开**商店机器**对话框。
2. 添加或移除属于该商店的机器。

你也可以在 **[机器](machines.md)** 界面将机器绑定到商店。

## 商店配方 { #store-recipes }

每个商店都有自己的一组已分配配方。

- 点击商店行（或分组树中的分组）上的**配方**图标，打开**商店配方**对话框以查看或调整已分配的配方。
- 点击**同步配方**图标以同步该商店的配方。

### 将配方导入分组

1. 在分组树中选择一个分组。
2. 点击**导入配方**。
3. 选择要导入到该分组各商店的配方。

若要从配方列表分发配方，请参见 **[将配方分发到商店](recipes.md#distributing-recipes-to-stores)**。

## 商店详情

点击商店行可打开其详情页，其中显示：

- **基本信息** —— 商店的主要信息。
- **机器** —— 关联到该商店的机器。
- **配方** —— 分配给该商店的配方。
