# :material-coffee-maker: Machines

The **Machines** screen lists the machines available to you and lets you bind them to stores, set their password, and review each machine's configuration and data.

> Machines are registered during the factory setup process. From the manager dashboard you configure and monitor machines; you do not create or delete them here.

## Overview

The machine list shows each machine's UUID, PLC UUID, model, hardware version, remark, the store it is bound to, and its creation date.

## Binding a Machine to a Store

- If the machine is **not bound**, click **Bind to Store**, choose the store and confirm.
- If the machine is **already bound**, its store name is shown as a button; click it to change the store.

## Unbinding a Machine

1. Click the **unlink** icon next to the bound store.
2. Confirm in the dialog. The machine is detached from the store.

## Changing the Machine Password

1. Click the **password** icon in the machine row.
2. Enter and confirm the new password.
3. Save.

## Channels

Click **Channels** to open the machine's channel configuration, which shows the machine's pots and the ingredients bound to them.

## Machine Details { #machine-details }

Click a machine row to open its details page, which contains:

- **Basic Info** – the machine's main information.
- **Channels** – the pots and their bound ingredients.
- **Production Records** – the drinks produced by this machine, with statistics. See **[Production Records](production_records.md)** and **[Statistics](statistics.md)**.
- **Cleaning** – the machine's cleaning data.
- **Activities** – the machine's activity log.
