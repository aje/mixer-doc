# :material-bottle-tonic-plus: 原料

原料（物料）是配方使用的基础物品。本页介绍如何创建和管理它们，以及如何从 Excel 导入。

> 若要选择某个配方使用哪些原料，请参见 **[配方原料](recipe_ingredients.md)**。

## 概览

**原料**界面列出你的原料，并可搜索、创建、编辑和删除它们。

![原料列表](../assets/images/placeholder.png)

*截图占位：原料列表。*

- **搜索** —— 在搜索框中输入关键字以筛选原料。

## 管理原料

### 创建原料

1. 点击**新建**。
2. 填写原料信息。
3. 保存。

### 编辑原料

1. 点击行上的**编辑**图标。
2. 更新字段。
3. 保存。

### 启用或停用原料

使用行中的**状态**开关。

### 删除原料

- **单个** —— 点击行上的**删除**图标并确认。
- **批量** —— 用复选框选择原料，然后点击工具栏中的**删除**并确认。

## 从 Excel 导入原料

1. 点击**上传**。
2. 选择 Excel 文件。
3. 文件中的原料将被导入到列表中。
