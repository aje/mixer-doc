# :material-bottle-tonic-plus: Ingredients

Ingredients (materials) are the raw items used by recipes. This page explains how to create and manage them, and how to import them from Excel.

> To choose which ingredients a specific recipe uses, see **[Recipe Ingredients](recipe_ingredients.md)**.

## Overview

The **Ingredients** screen lists your ingredients and lets you search, create, edit and delete them.

![Ingredients list](../assets/images/placeholder.png)

*Screenshot placeholder: the ingredients list.*

- **Search** – type a keyword in the search box to filter ingredients.

## Managing Ingredients

### Create an ingredient

1. Click **New**.
2. Fill in the ingredient details.
3. Save.

### Edit an ingredient

1. Click the **edit** icon on the row.
2. Update the fields.
3. Save.

### Enable or disable an ingredient

Use the **status** toggle in the row.

### Delete an ingredient

- **Single** – click the **delete** icon on the row and confirm.
- **Batch** – select ingredients with the checkboxes, then click **Delete** in the toolbar and confirm.

## Importing Ingredients from Excel

1. Click **Upload**.
2. Select the Excel file.
3. The ingredients from the file are imported into the list.
