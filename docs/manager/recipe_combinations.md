# :material-view-grid-plus: Recipe Combinations

Combinations define the exact ingredient amounts a recipe uses for each combination of its customization values. This page is part of the **[recipe configuration](recipes.md#recipe-configuration)**.

## Overview

When a recipe has customizations (for example *Size: Small / Large* and *Sugar: 50% / 100%*), the system generates one row for every possible combination of the selected values. For each combination you enter how much of each ingredient the recipe uses.

## Prerequisites

Before configuring combinations, make sure the recipe already has:

- its **[ingredients](recipe_ingredients.md)** selected, and
- its **[customizations](recipe_customization.md)** selected.

## Setting Ingredient Amounts

1. Open the recipe details and go to the **Combinations** section.
2. For each combination row, enter the amount for each ingredient column.
3. Use the per‑combination **Others** option to set additional values for that combination when needed.
4. Save your changes.

The **overall** totals are calculated from the amounts you enter, so you can verify each combination at a glance.
