# :material-store: Stores

Stores represent the physical locations that run your machines. This page explains how to organize stores into groups, create and edit stores, link machines, and manage the recipes assigned to each store.

## Overview

The **Stores** screen has two areas:

- **Store Groups** (left) – a tree of groups used to organize your stores.
- **Stores** (right) – the list of stores, optionally filtered by the selected group.

## Store Groups

Use the group tree on the left to filter and organize stores.

- Select **All** to list every store, or select a group to list only its stores.
- Use the **expand / collapse** button to show or hide the group panel.
- Click the **settings** (gear) icon to open the **Store Groups** manager, where you create, rename and remove groups.

## Managing Stores

### Create a store

1. (Optional) Select a group on the left so the new store is created under it.
2. Click **New**.
3. Fill in the store details (code, name, type, group, external code, tags, users).
4. Save.

### Edit a store

1. Click the **edit** icon on the store row.
2. Update the fields.
3. Save.

### Enable or disable a store

Use the **status** toggle in the store row to activate or deactivate a store.

### Delete a store

1. Click the **delete** icon on the store row.
2. Confirm in the dialog.

## Linking Machines to a Store

1. Click the **machines** icon on the store row to open the **Store Machines** dialog.
2. Add or remove the machines that belong to this store.

You can also bind a machine to a store from the **[Machines](machines.md)** screen.

## Store Recipes { #store-recipes }

Each store has its own set of assigned recipes.

- Click the **recipes** icon on a store row (or on a group in the tree) to open the **Store Recipes** dialog and review or adjust the assigned recipes.
- Click the **sync recipes** icon to synchronize the store's recipes.

### Import recipes into a group

1. Select a group in the tree.
2. Click **Import Recipes**.
3. Choose the recipes to import into the group's stores.

For distributing recipes from the recipe list, see **[Distributing Recipes to Stores](recipes.md#distributing-recipes-to-stores)**.

## Store Details

Click a store row to open its details page, which shows:

- **Basic Info** – the store's main information.
- **Machines** – the machines linked to the store.
- **Recipes** – the recipes assigned to the store.
