# :material-rocket-launch: 入门指南

按照以下步骤准备容器并分配配方。

## 开始前

1. 确保机器已连接网络，并确认空秤显示为 `0`。
   ![检查网络和空秤占位符](assets/images/placeholder.png)

## 绑定原料

1. 打开**容器**页面。
   ![打开容器占位符](assets/images/placeholder.png)
2. 点击未分配原料的容器。
   ![选择空容器占位符](assets/images/placeholder.png)
3. 从可用原料列表中选择原料。
   ![选择原料占位符](assets/images/placeholder.png)
4. 确认容器上显示原料名称。
   ![已绑定原料占位符](assets/images/placeholder.png)

## 填充和初始化容器

1. 点击容器上的**菜单图标（三个竖点）**。
   ![打开容器菜单占位符](assets/images/placeholder.png)
2. 选择**补充**。
   ![选择补充占位符](assets/images/placeholder.png)
3. 将滑块调整到新的总容量。
   ![调整容量占位符](assets/images/placeholder.png)
4. 点击**加满**。
   ![加满占位符](assets/images/placeholder.png)
5. 等待短暂的初始化完成（如开始初始化）。
   ![初始化占位符](assets/images/placeholder.png)

## 出料

1. 打开**配方**。
   ![打开配方占位符](assets/images/placeholder.png)
2. 选择配方。
   ![选择配方占位符](assets/images/placeholder.png)
3. 选择所需规格。
   ![选择规格占位符](assets/images/placeholder.png)
4. 检查原料是否可用，以及出料口是否已校准。
   ![检查可用性占位符](assets/images/placeholder.png)
5. 将杯子放在出料口下方。
   ![放置杯子占位符](assets/images/placeholder.png)
6. 点击**出料**。
   ![出料占位符](assets/images/placeholder.png)
7. 等待出料流程完成。
   ![出料进度占位符](assets/images/placeholder.png)
8. 查看完成摘要。
   ![完成摘要占位符](assets/images/placeholder.png)
