# :material-view-dashboard: User Guide: Home Screen Dashboard

The Home screen provides an overview of the machine status, activity, and maintenance needs.

![Home Screen Dashboard](assets/images/en/home/home-screen-dashboard.png)

## 1. Machine Information
Shows the current store and machine details.

- **Store and machine details**: Shows the store, device model, hardware version, and PLC UUID.
- **Network status**: Shows a warning if WiFi or internet connectivity is lost.
- **Refresh**: Updates the information from the server.

## 2. Hardware Component Status
Shows the status and readings of the machine's critical hardware.

![Hardware Status Panel](assets/images/en/home/hardware-status-panel.png)

- **Scale**: Shows the current net weight and online status. Tap it to calibrate or test the scale.
- **Motors**: Shows active motor channels and connection status.
- **Heaters**: Shows the current temperature.
- **Scanner**: Shows whether the scanner is ready.

## 3. Usage Statistics
Summarizes machine performance and maintenance needs.

![Usage Statistics Cards](assets/images/en/home/usage-statistics-cards.png)

- **Calibration Needed**: Shows pots requiring calibration.
- **Today's Orders**: Shows recipes successfully produced today.
- **This Week (Failed)**: Shows failed production attempts this week.
- **This Week (Success)**: Shows successful productions this week.

## 4. Recent Recipes & Activity
Lists recent production records.

![Recent Activity Feed](assets/images/en/home/recent-activity-feed.png)

- Shows the recipe, target volume, weight error, order ID, status, and start time.
- Tap a recipe to open its details.

## 5. Low/Empty Pots Management
Shows low or empty ingredient pots.

![Low Ingredients Monitor](assets/images/en/home/low-ingredients-monitor.png)

- **Low ingredients**: Lists pots below 1500 ml or empty.
- **Refilling**: Tap an ingredient to open the refill interface.

---
*Tip: Check the Hardware Status panel first when a red hardware warning appears.*
