# :material-water-plus: 填充和初始化容器

1. 用所需液体补充容器。
   ![补充容器占位符](assets/images/placeholder.png)
2. 将大杯放在分配器下方。
   ![放置大杯占位符](assets/images/placeholder.png)
3. 打开**容器**页面。
   ![打开容器占位符](assets/images/placeholder.png)
4. 点击容器上的**菜单图标（三个竖点）**。
   ![打开容器菜单占位符](assets/images/placeholder.png)
5. 选择**补充**。
   ![选择补充占位符](assets/images/placeholder.png)
6. 将滑块调整到新的总容量。
   ![调整容量占位符](assets/images/placeholder.png)
7. 点击**加满**。
   ![加满占位符](assets/images/placeholder.png)
8. 等待短暂的初始化完成（如开始初始化）。
   ![初始化占位符](assets/images/placeholder.png)

## 补充多个容器

1. 用所需液体补充容器。
   ![补充容器占位符](assets/images/placeholder.png)
2. 将大杯放在分配器下方。
   ![放置大杯占位符](assets/images/placeholder.png)
3. 打开**容器**页面。
   ![打开容器占位符](assets/images/placeholder.png)
4. 点击底部的**选择**。
   ![选择容器占位符](assets/images/placeholder.png)
5. 选择已补充的容器。
   ![选择已补充容器占位符](assets/images/placeholder.png)
6. 点击**补充**。
   ![补充所选容器占位符](assets/images/placeholder.png)
7. 等待容器逐个初始化。
   ![容器初始化占位符](assets/images/placeholder.png)
8. 确认该流程。
   ![确认补充占位符](assets/images/placeholder.png)
