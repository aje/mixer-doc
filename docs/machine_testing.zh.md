# :material-clipboard-check: 机器测试清单

将机器送到门店前，完成以下清单。

## 容器

- [ ] 将原料绑定到容器，并确认容器显示原料名称。
  ![绑定容器占位符](assets/images/placeholder.png)
- [ ] 打开容器菜单，选择**解绑容器**，并确认原料已移除。
  ![解绑容器占位符](assets/images/placeholder.png)
- [ ] 校准每个容器，并确认校准完成。
  ![校准容器占位符](assets/images/placeholder.png)

## 机器组件

- [ ] 测试屏幕，并确认触摸有响应。
  ![屏幕测试占位符](assets/images/placeholder.png)
- [ ] 测试网络连接。
  ![网络测试占位符](assets/images/placeholder.png)
- [ ] 测试秤，并确认重量读数正确。
  ![秤测试占位符](assets/images/placeholder.png)
- [ ] 测试扫描仪。
  ![扫描仪测试占位符](assets/images/placeholder.png)
- [ ] 测试声音。
  ![声音测试占位符](assets/images/placeholder.png)
- [ ] 测试加热器（如已安装）。
  ![加热器测试占位符](assets/images/placeholder.png)
- [ ] 运行电机，并确认运行稳定。
  ![电机稳定性测试占位符](assets/images/placeholder.png)

## 配方和准确性

- [ ] 出料多个配方，并确认每个配方都成功完成。
  ![多个配方测试占位符](assets/images/placeholder.png)
- [ ] 将每个配方的出料量与所需规格进行比较，并确认准确性。
  ![配方准确性测试占位符](assets/images/placeholder.png)

## 补充原料

- [ ] 补充一个容器，并确认补充流程成功完成。
  ![补充测试占位符](assets/images/placeholder.png)
- [ ] 确认机器已准备好发送到门店。
  ![机器准备就绪占位符](assets/images/placeholder.png)
