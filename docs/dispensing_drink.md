# :material-glass-cocktail: Dispensing a Drink

## Using a QR Code

1. Place a cup under the dispenser.
   ![Place Cup Placeholder](assets/images/placeholder.png)
2. Scan the QR code containing recipe and its specifications.
   ![Scan QR Code Placeholder](assets/images/placeholder.png)
3. Wait for the dispensing process to finish automatically.
   ![Automatic Dispensing Placeholder](assets/images/placeholder.png)
4. Check the completion summary.
   ![Completion Summary Placeholder](assets/images/placeholder.png)

## Using the Recipe Page

1. Open **Recipes**.
   ![Open Recipes Placeholder](assets/images/placeholder.png)
2. Select a recipe.
   ![Select Recipe Placeholder](assets/images/placeholder.png)
3. Select the specifications.
   ![Select Specifications Placeholder](assets/images/placeholder.png)
4. Check that the ingredients are available and the dispensers are calibrated.
   ![Check Availability Placeholder](assets/images/placeholder.png)
5. Place a cup under the dispenser.
   ![Place Cup Placeholder](assets/images/placeholder.png)
6. Tap **Dispense**.
   ![Dispense Placeholder](assets/images/placeholder.png)
7. Wait for the dispensing process to finish.
   ![Dispensing Progress Placeholder](assets/images/placeholder.png)
8. Check the completion summary.
   ![Completion Summary Placeholder](assets/images/placeholder.png)
