# :material-glass-cocktail: Dispensing a Drink

## Using a QR Code

1. Place a cup under the dispenser. 
2. Scan the QR code containing recipe and its specifications. 
3. Wait for the dispensing process to finish automatically.
   ![Dispensing Progress Placeholder](assets/images/cn/recipe/dispense-loading.png)
4. Check the completion summary.
   ![Check the completion summary](assets/images/cn/recipe/confirm.png)

## Using the Recipe Page

1. Open **Recipes**.
   ![Open Recipes Placeholder](assets/images/cn/recipe/recipes.png)
2. Select a recipe. 
3. Select the specifications.
   ![Select Specifications Placeholder](assets/images/cn/recipe/recipes-details.png)
4. Place a cup under the dispenser. 
5. Tap **Dispense**.
   ![Dispense Placeholder](assets/images/cn/recipe/tap-dispense.png)
6. Wait for the dispensing process to finish.
   ![Dispensing Progress Placeholder](assets/images/cn/recipe/dispense-loading.png)
7. Check the completion summary.
   ![Check the completion summary](assets/images/cn/recipe/confirm.png)
